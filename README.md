# Django-go

Учебный проект интернет-магазина на Django.

Проект развивается поэтапно в рамках домашних работ курса.

## Домашняя работа 27

В рамках домашней работы реализована пользовательская аутентификация, регистрация, авторизация по электронной почте и ограничение доступа к управлению товарами.

## Реализовано

### Пользователи

- создано отдельное приложение `users`;
- приложение добавлено в `INSTALLED_APPS`;
- реализована кастомная модель пользователя;
- модель пользователя наследуется от `AbstractUser`;
- стандартное поле `username` отключено;
- электронная почта используется как основное поле авторизации;
- добавлены дополнительные поля:
  - аватар;
  - номер телефона;
  - страна;
- модель пользователя зарегистрирована в административной панели.

### Регистрация

- реализована форма регистрации пользователя;
- форма содержит:
  - электронную почту;
  - пароль;
  - подтверждение пароля;
- после успешной регистрации пользователь автоматически авторизуется;
- после регистрации выполняется переход на главную страницу;
- после успешной регистрации отправляется приветственное письмо;
- для разработки используется console mailer.

### Авторизация

- реализована форма входа;
- пользователь авторизуется по электронной почте и паролю;
- реализован выход из системы;
- после успешного входа пользователь перенаправляется на главную страницу;
- после выхода пользователь также перенаправляется на главную страницу;
- меню отображает разные ссылки в зависимости от состояния авторизации пользователя.

## Ограничение доступа

Главная страница со списком товаров остаётся общедоступной.

Для неавторизованных пользователей закрыт доступ к:

- детальной странице товара;
- созданию товара;
- редактированию товара;
- удалению товара.

Ограничение реализовано через `LoginRequiredMixin`.

При попытке открыть защищённую страницу неавторизованный пользователь перенаправляется на страницу входа.

## Основные маршруты пользователей

Регистрация:

`/users/register/`

Авторизация:

`/users/login/`

Выход:

`/users/logout/`

## Основные маршруты товаров

Публичный список товаров:

`/`

Детальная страница товара:

`/products/<int:pk>/`

Создание товара:

`/products/create/`

Редактирование товара:

`/products/<int:pk>/edit/`

Удаление товара:

`/products/<int:pk>/delete/`

## Переменные окружения

Подключение к PostgreSQL настраивается через файл `.env`.

Пример:

```env
DATABASE_NAME=django_shop
DATABASE_USER=postgres
DATABASE_PASSWORD=your_password
DATABASE_HOST=localhost
DATABASE_PORT=5432
```

Файл `.env` не должен попадать в репозиторий.

## Почта

Для локальной разработки используется console mailer:

```python
MAILERS = {
    "default": {
        "BACKEND": "django.core.mail.backends.console.EmailBackend",
    },
}
```

Приветственное письмо после регистрации выводится в терминал.

## Установка

Для управления зависимостями используется Poetry.

```bash
poetry install
```

## Миграции

Создание миграций:

```bash
python manage.py makemigrations
```

Применение миграций:

```bash
python manage.py migrate
```

## Запуск проекта

```bash
python manage.py runserver
```

После запуска проект доступен по адресу:

`http://127.0.0.1:8000/`
