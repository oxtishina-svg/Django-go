# Django-go

Учебный проект интернет-магазина на Django.

Проект развивается поэтапно в рамках домашних работ курса.

## Домашняя работа 26.1

В рамках домашней работы реализован полный CRUD для товаров с использованием Django-форм, добавлена кастомная валидация и стилизация формы.

## Реализовано

### CRUD продуктов

- реализовано создание продуктов;
- реализован просмотр списка продуктов;
- реализован просмотр отдельного продукта;
- реализовано редактирование продуктов;
- реализовано удаление продуктов;
- для создания и редактирования используется `ProductForm`;
- форма реализована на основе `ModelForm`.

### Валидация запрещённых слов

В отдельную константу вынесен список запрещённых слов:

- казино;
- криптовалюта;
- крипта;
- биржа;
- дешево;
- бесплатно;
- обман;
- полиция;
- радар.

Проверка выполняется для полей:

- `name`;
- `description`.

Регистр при проверке игнорируется.

Если название или описание содержит запрещённое слово, пользователю выводится понятное сообщение об ошибке.

### Валидация цены

Для поля `price` реализован метод `clean_price`.

Цена продукта не может быть отрицательной.

При вводе отрицательного значения форма не проходит валидацию и отображает сообщение:

`Цена продукта не может быть отрицательной.`

### Стилизация формы

Форма продукта стилизована через метод `__init__`.

Для стандартных полей используется Bootstrap-класс:

`form-control`

Для чекбоксов предусмотрен класс:

`form-check-input`

Для полей добавлены плейсхолдеры.

## Основные маршруты товаров

Главная страница:

`/`

Создание продукта:

`/products/create/`

Детальная страница:

`/products/<int:pk>/`

Редактирование:

`/products/<int:pk>/edit/`

Удаление:

`/products/<int:pk>/delete/`

## Переменные окружения

Подключение к PostgreSQL настраивается через файл `.env`.

Пример значений находится в `.env_template`:

```env
DATABASE_NAME=django_shop
DATABASE_USER=postgres
DATABASE_PASSWORD=your_password
DATABASE_HOST=localhost
DATABASE_PORT=5432
```

Файл `.env` не должен попадать в репозиторий.

## Установка

Для управления зависимостями используется Poetry.

```bash
poetry install
```

## Миграции

Создание миграций:

```bash
python manage.py makemigrations
```

Применение миграций:

```bash
python manage.py migrate
```

## Запуск проекта

```bash
python manage.py runserver
```

После запуска проект доступен по адресу:

`http://127.0.0.1:8000/`

## Проверка проекта

Проверка конфигурации Django:

```bash
python manage.py check
```

```bash

flake8 .
```
