# Django-go

Учебный проект интернет-магазина на Django.

Проект развивается поэтапно в рамках домашних работ курса.

## Домашняя работа 28

В рамках домашней работы реализована система прав доступа для модерации продуктов и добавлена логика владельца товара.

## Реализовано

### Публикация продуктов

- в модель `Product` добавлено поле `is_published`;
- поле имеет тип `BooleanField`;
- значение по умолчанию — `False`;
- статус публикации отображается на странице товара;
- владелец товара может установить статус публикации через форму;
- модератор может снять товар с публикации.

### Кастомное право

Для модели `Product` добавлено кастомное право:

`can_unpublish_product`

Право позволяет снимать продукт с публикации.

### Группа модераторов

Реализована группа:

`Модератор продуктов`

Группе назначены права:

- `can_unpublish_product`;
- `delete_product`.

Для создания группы и назначения прав реализована кастомная management-команда:

```bash
python manage.py create_product_moderator_group
```

### Владелец продукта

В модель `Product` добавлено поле:

`owner`

Поле связано с моделью пользователя через `ForeignKey`.

При создании нового продукта владелец автоматически определяется по текущему авторизованному пользователю.

Пользователь не выбирает владельца вручную через форму.

### Ограничение доступа

Редактировать продукт может только пользователь, который его создал.

Удалять продукт могут:

- владелец продукта;
- пользователь с правом `catalog.delete_product`.

Снимать продукт с публикации может только пользователь с правом:

`catalog.can_unpublish_product`

Для проверки прав используются:

- `LoginRequiredMixin`;
- `UserPassesTestMixin`;
- `PermissionRequiredMixin`.

### Управление интерфейсом

На странице продукта кнопки отображаются в зависимости от прав пользователя.

Владелец продукта видит:

- кнопку редактирования;
- кнопку удаления.

Модератор продукта видит:

- кнопку удаления;
- кнопку снятия товара с публикации, если товар опубликован.

Обычный пользователь, который не является владельцем товара, не может редактировать или удалять чужой продукт.

## Модель Product

Основные поля:

- `name` — наименование;
- `description` — описание;
- `image` — изображение;
- `category` — категория;
- `price` — цена;
- `is_published` — статус публикации;
- `owner` — владелец продукта;
- `created_at` — дата создания;
- `updated_at` — дата последнего изменения.

## Основные маршруты товаров

Список товаров:

`/`

Создание товара:

`/products/create/`

Детальная страница:

`/products/<int:pk>/`

Редактирование:

`/products/<int:pk>/edit/`

Удаление:

`/products/<int:pk>/delete/`

Снятие с публикации:

`/products/<int:pk>/unpublish/`

## Кастомная команда

Создание группы модераторов:

```bash
python manage.py create_product_moderator_group
```

Команда:

- создаёт группу `Модератор продуктов`, если её ещё нет;
- получает необходимые разрешения;
- назначает группе права на удаление продуктов и снятие их с публикации.

## Переменные окружения

Подключение к PostgreSQL настраивается через файл `.env`.

Пример:

```env
DATABASE_NAME=django_shop
DATABASE_USER=postgres
DATABASE_PASSWORD=your_password
DATABASE_HOST=localhost
DATABASE_PORT=5432
```

Файл `.env` не должен попадать в репозиторий.

## Установка

Для управления зависимостями используется Poetry.

```bash
poetry install
```

## Миграции

Создание миграций:

```bash
python manage.py makemigrations
```

Применение миграций:

```bash
python manage.py migrate
```

## Запуск проекта

```bash
python manage.py runserver
```

После запуска проект доступен по адресу:

`http://127.0.0.1:8000/`
