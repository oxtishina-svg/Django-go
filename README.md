# Django-go

Учебный проект интернет-магазина на Python.

## Домашняя работа 21.2

В рамках домашней работы реализовано простое веб-приложение без использования Django.

### Реализовано

- HTML-страницы с использованием Bootstrap;
- главная страница;
- страница каталога;
- страница категории;
- страница контактов;
- страница 404;
- HTTP-сервер на Python;
- обработка GET-запросов;
- обработка POST-запросов формы обратной связи;
- чтение HTML-файлов через контекстный менеджер;
- ответы сервера с `Content-Type: text/html`.
