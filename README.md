# Django-go

Учебный проект интернет-магазина на Django.

Проект развивается поэтапно в рамках домашних работ курса.

## Домашняя работа 25

В рамках домашней работы контроллеры приложения `catalog` переведены с FBV на CBV, а также реализовано приложение блога с полным CRUD.

## Реализовано

### Catalog

- все контроллеры приложения `catalog` переведены на CBV;
- главная страница реализована через `ListView`;
- страница товара реализована через `DetailView`;
- страница контактов реализована через `TemplateView`;
- сохранён динамический вывод товаров из базы данных;
- сохранена работа с PostgreSQL.

### Blog

- создано приложение `blog`;
- приложение зарегистрировано в `INSTALLED_APPS`;
- создан отдельный `urls.py`;
- маршруты блога подключены через `include`;
- все URL блога начинаются с `/blogs/`;
- создана модель `BlogPost`;
- реализован полный CRUD через CBV;
- создан список опубликованных статей;
- реализована детальная страница статьи;
- реализовано создание статьи;
- реализовано редактирование статьи;
- реализовано удаление статьи;
- при открытии статьи увеличивается счётчик просмотров;
- в списке отображаются только опубликованные статьи;
- после редактирования происходит переход на отредактированную статью;
- шаблоны блога наследуются от `base.html`;
- используется общий подшаблон меню.

## Модель BlogPost

Поля:

- `title` — заголовок;
- `content` — содержимое;
- `preview` — изображение-превью;
- `created_at` — дата создания;
- `is_published` — признак публикации;
- `views_count` — количество просмотров.

## Маршруты блога

Список статей:

`/blogs/`

Создание статьи:

`/blogs/create/`

Детальная страница:

`/blogs/<int:pk>/`

Редактирование:

`/blogs/<int:pk>/edit/`

Удаление:

`/blogs/<int:pk>/delete/`

## Переменные окружения

Подключение к PostgreSQL настраивается через файл `.env`.

Пример значений находится в `.env_template`:

```env
DATABASE_NAME=django_shop
DATABASE_USER=postgres
DATABASE_PASSWORD=your_password
DATABASE_HOST=localhost
DATABASE_PORT=5432
```

Файл `.env` не должен попадать в репозиторий.

## Установка

Для управления зависимостями используется Poetry.

```bash
poetry install
```

## Миграции

Создание миграций:

```bash
python manage.py makemigrations
```

Применение миграций:

```bash
python manage.py migrate
```

## Запуск проекта

```bash
python manage.py runserver
```

После запуска проект доступен по адресу:

`http://127.0.0.1:8000/`

Блог доступен по адресу:

`http://127.0.0.1:8000/blogs/`
