# Django-go

Учебный проект интернет-магазина на Django.

Проект развивается поэтапно в рамках домашних работ курса.

## Домашняя работа 24

В рамках домашней работы реализован динамический вывод товаров, добавлена детальная страница товара и переработана структура HTML-шаблонов с использованием базового шаблона и подшаблонов.

## Реализовано

- на главной странице отображается список товаров из базы данных;
- данные товаров получаются через `Product.objects.all()`;
- для вывода товаров используется шаблонный цикл `for`;
- описание товара на главной странице обрезается до 100 символов;
- добавлена детальная страница товара;
- детальная страница доступна по адресу `/products/<int:pk>/`;
- маршрут детальной страницы имеет имя `product_detail`;
- товар на детальной странице получается по `pk`;
- на детальной странице отображаются:
  - название;
  - описание;
  - цена;
  - изображение;
  - категория;
- реализованы переходы с главной страницы на страницу товара и обратно;
- создан базовый шаблон `base.html`;
- шаблоны страниц наследуются от базового шаблона;
- создан подшаблон главного меню;
- меню подключается через `{% include %}`;
- используется Bootstrap;
- сохранена работа с PostgreSQL, моделями, миграциями и админкой из предыдущей домашней работы.

## Структура шаблонов

```text
templates/
├── includes/
│   └── menu.html
├── base.html
├── contacts.html
├── home.html
```

## Основные маршруты

Главная страница:

```text
/
```

Страница контактов:

```text
/contacts/
```

Детальная страница товара:

```text
/products/<int:pk>/
```

Административная панель:

```text
/admin/
```

## Модели

### Category

Поля:

- `name` — наименование категории;
- `description` — описание категории.

### Product

Поля:

- `name` — наименование товара;
- `description` — описание товара;
- `image` — изображение;
- `category` — категория товара;
- `price` — цена;
- `created_at` — дата создания;
- `updated_at` — дата последнего изменения.

## Переменные окружения

Подключение к PostgreSQL настраивается через файл `.env`.

Пример находится в `.env_template`:

```env
DATABASE_NAME=django_shop
DATABASE_USER=postgres
DATABASE_PASSWORD=your_password
DATABASE_HOST=localhost
DATABASE_PORT=5432
```

Файл `.env` не должен попадать в репозиторий.

## Установка

Для управления зависимостями используется Poetry.

```bash
poetry install
```

## Миграции

Создание миграций:

```bash
python manage.py makemigrations
```

Применение миграций:

```bash
python manage.py migrate
```

## Запуск проекта

```bash
python manage.py runserver
```

После запуска проект доступен по адресу:

```text
http://127.0.0.1:8000/
```
